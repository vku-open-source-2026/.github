# vku-open-source-2026/.github

Organization profile and community metadata repository for [**VKU Open Source 2026**](https://github.com/vku-open-source-2026) — home of the **Synapse DX-OS** ecosystem.

👉 **View the rendered organization profile:** [`profile/README.md`](profile/README.md)

## Structure

```text
profile/
  README.md   Public GitHub Organization profile displayed at github.com/vku-open-source-2026
  assets/     Light-mode live screenshots and Synapse brand lockups
```

## Quickstart & Usage

### Preview Locally

Clone this repository and preview [`profile/README.md`](profile/README.md) in any GitHub Flavored Markdown viewer:

```bash
git clone git@github.com:vku-open-source-2026/.github.git
cd .github
```

### Updating Organization Profile Screenshots

1. Capture 1440×900 **Light Mode** screenshots from the live portals (`synapseone.space`, `synapsedx.sbs`, `synapsecity.sbs`, `sos.synapsecity.sbs/map`).
2. Save updated PNGs into `profile/assets/` keeping relative `./assets/<name>.png` paths inside `profile/README.md` so images resolve both on the organization overview tab and inside the repository view.
3. Commit and push to `main`.
